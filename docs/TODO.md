# VLM 服务开发 TODO

## 背景

- 目标：在单机单卡 H100 80G 上部署一个自用的 VLM 推理服务
- 模型：`Qwen3.5-27B`
- 权重：已下载到本地
- 运行方式：代码部署到云端服务器执行，本地开发机不做 LLM 推理调试
- 调用方式：同机另一个进程通过本地接口调用
- 取舍：先做简单版本，不追求高并发，不优先做复杂监控和调度

## 第一阶段目标

先完成一个最小可用版本：

- 服务能启动
- 能加载本地模型
- 能接收 `图像 + 文本`
- 能返回推理结果
- 提供最基本的健康检查接口
- 支持本机 HTTP 调用
- 本地开发阶段不要求真实加载大模型，真实推理联调放到云端服务器完成
