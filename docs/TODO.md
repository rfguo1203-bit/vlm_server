对照 [vlm_h100_plan.md](/Users/rkos/Workspace/vlm_server/docs/vlm_h100_plan.md)，下面这些仍然没有真正落地，或者只落了最小版本。

### 高优先级

- [ ] 请求级超时控制
  - 配置里已有 `REQUEST_TIMEOUT_SECONDS`
  - 当前推理链路里还没有真正使用
- [ ] 串行/低并发保护
  - 当前没有 `Semaphore`、队列或并发上限控制
  - 多请求同时进入时会直接打到后端 engine
- [ ] 更稳定的异常处理和错误码
  - 现在主要依赖 `HTTPException`
  - 还没有统一错误码、错误分类和全局异常处理
- [ ] 请求日志和 request id
  - 当前只有启动时 `print`

### 中优先级

- [ ] 输入安全收口
  - 目前支持任意本地路径和 `file://`
  - 还没有目录白名单或路径访问边界
- [ ] 输出与资源保护
  - 目前限制了 `max_tokens` 的最小值，但没有统一上限保护
  - 还没有更明确的 OOM 防护策略
- [ ] 基础测试补齐
  - 当前仓库没有成体系的 `tests/`
  - 缺少图片输入、错误场景、接口响应的自动化测试
- [ ] 部署化配置
  - 还没有 `systemd` / `supervisord` 配置
  - 还没有正式部署说明和开机自启方案

### 低优先级

- [ ] Prometheus `/metrics`
- [ ] JSON 结构化日志
- [ ] 队列长度与拒绝策略
- [ ] 流式输出
- [ ] UDS 通信
- [ ] 业务鉴权 / ACL
- [ ] 压测与性能调优
