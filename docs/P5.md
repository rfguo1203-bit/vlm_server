# P5 联调说明

## 目标

P5 分成两部分：

1. 代码和联调脚本准备完成
2. 在云端服务器上真正跑通一次端到端请求

当前仓库内已完成第 1 部分，第 2 部分需要你在服务器上执行。

## 已完成的开发项

- `run_server.sh` 已支持默认参数和 `.env` 覆盖
- `run_server.sh` 依赖当前已激活的 Python 环境
- `run_client.sh` 已提供完整联调请求
- `run_client.sh` 同时支持：
  - `REQUEST_MODE=path`
  - `REQUEST_MODE=base64`
- 请求和响应会默认落盘到本地文件，方便排查

## 默认参数

### 服务端默认参数

- `GPU_ID=0`
- `CUDA_VISIBLE_DEVICES` 默认跟随 `GPU_ID`
- `HOST=127.0.0.1`
- `PORT=8000`
- `MODEL_NAME=Qwen3.5-27B`
- `MODEL_PATH=/home/user/g00806422/data/weight/Qwen3.5-27B`
- `INFERENCE_BACKEND=vllm`
- `SKIP_MODEL_LOAD=false`

### 客户端默认参数

- `SERVER_URL=http://127.0.0.1:8000`
- `MODEL_NAME=Qwen3.5-27B`
- `REQUEST_MODE=path`
- `IMAGE_PATH=/tmp/example.jpg`
- `PROMPT=请描述这张图片中的主要内容。`
- `MAX_TOKENS=256`
- `TEMPERATURE=0.1`

## 服务器执行方式

### 1. 启动服务

```bash
conda activate vllm
bash scripts/run_server.sh
```

如果要指定单卡 GPU，例如用第 3 张卡：

```bash
conda activate vllm
GPU_ID=3 bash scripts/run_server.sh
```

或者直接显式传：

```bash
conda activate vllm
CUDA_VISIBLE_DEVICES=3 bash scripts/run_server.sh
```

### 2. 发起路径图片请求

```bash
IMAGE_PATH=/tmp/example.jpg bash scripts/run_client.sh
```

### 3. 发起 base64 图片请求

```bash
REQUEST_MODE=base64 IMAGE_PATH=/tmp/example.jpg bash scripts/run_client.sh
```

## 建议你在服务器上准备的图片

请自行准备一张联调用图片，例如：

```text
/tmp/example.jpg
```
